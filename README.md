# willowholler.com

The Willow Holler website: the home page and the HighGround product page. Plain HTML and CSS, no build step.
Hosted on GitHub Pages with the custom domain www.willowholler.com (the `CNAME` file holds it).

```
index.html             willowholler.com
highground/index.html  willowholler.com/highground
styles.css             shared styles (Direction A, "Prairie ledger")
willowholler-*.webp/png  Willow Holler emblem and tab icon
highground-*.png         HighGround logo, wordmark (colour and light), tab icon
404.html               page-not-found
CNAME                  www.willowholler.com (keep this file)
```

- The HighGround app lives separately at https://highground.willowholler.com (repository `highground`).
- The demo district's public link appears three times in `highground/index.html`; search for "DEMO LINK".
- No personal names on the site, by decision (1 Oct 2026).
