# willowholler.com

The Willow Holler website. Plain HTML and CSS, no build step.
Hosted on GitHub Pages with the custom domain www.willowholler.com (the `CNAME` file holds it).

```
index.html               willowholler.com: one page, Willow Holler intro + HighGround + about (since 24 Nov 2026)
highground/index.html    forwards old links to willowholler.com/#highground
styles.css               shared styles (Direction A, "Prairie ledger"); the home page block is at the end
hero-school-sunrise.webp hero photo
willowholler-*.webp/png  Willow Holler emblem and tab icon
highground-*.png         HighGround logo, wordmark (colour and light), tab icon
404.html                 page-not-found
CNAME                    www.willowholler.com (keep this file)
```

- The HighGround app lives separately at https://highground.willowholler.com (repository `highground`).
- One page while there is one product. When a second product arrives, move the HighGround sections
  (`#highground` to `#trust`) to their own page and give the home page product cards.
- Site rules: no personal names (1 Oct 2026); no mention of a school-board role; no real district as proof;
  no public demo link; no mock-ups or made-up-figure illustrations; no red in graphics.
  Describe only what the app has built.
